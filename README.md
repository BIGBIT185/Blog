# 刘成魁的个人博客

[访问博客](https://bigbit185.github.io/Blog/)

以软件工程、AI 应用与机器人研究为主题的中文个人博客。纯静态 HTML、CSS 与 JavaScript，无需安装依赖或构建，可以直接部署到 GitHub Pages。

## 页面内容

- 个人介绍、精选项目、教育与获奖经历。
- 七篇首页笔记与八个项目入口，均有独立可分享页面；新增对称破缺、快点、空地协同与王者荣耀 AI。
- 分类筛选、关键词搜索、可记忆的深浅主题。
- 自适应手机、平板与桌面布局，支持键盘导航和减少动态效果的系统偏好。
- 图形为站内原创 SVG 概念示意，无外部图片、字体、追踪或服务依赖。

## 本地浏览

直接打开 `index.html` 即可，也可以在本目录运行 `python -m http.server 8765`，访问 `http://localhost:8765`。

## 部署到 GitHub Pages

1. 本站使用公开仓库 `BIGBIT185/Blog`，已配置 GitHub Pages 从 `main` 分支根目录发布。发布设置位于 https://github.com/BIGBIT185/Blog/settings/pages 。
2. 将本文件夹的内容上传到仓库根目录，保留 `articles` 目录结构。
3. 在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/(root)**，保存。
4. 等待 GitHub Pages 发布，打开 Pages 设置中显示的正式链接。

所有站内资源使用相对路径，兼容账号站点和项目站点。

## 更新内容

- 首页信息、项目列表和笔记入口：`index.html`。
- 正文：`articles/` 中的 HTML 文件。
- 视觉样式：`style.css`。
- 主题与筛选：`main.js`。
- 增加笔记时，在首页复制一张 `.note-card`，修改分类、标题、摘要与链接，并创建对应文章页。
